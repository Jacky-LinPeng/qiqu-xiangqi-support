简体中文

1. 游戏内不收集个人数据

游戏无需注册登录，不要求姓名、邮箱、生日或身份信息。没有广告、分析统计、追踪 SDK、内购、聊天或排行榜。我们不接收棋局、学习记录或设备标识符，不使用广告标识符，不进行跨 App 追踪。

2. 本地记录与离线

对局、悔棋历史、难度、语言、声音与动画设置、教程及残局完成记录保存在设备本地，用于恢复游戏。iOS App 内置游戏资源，不需要网络运行。网页版本可缓存资源供离线使用。游戏不会把记录上传给开发者。设备或系统管理的备份以您自己的系统设置为准。

3. 权限与删除

游戏不申请相机、麦克风、定位、联系人或照片访问。音效在设备本地合成播放，不录音。可通过设置中的“清除本地记录”删除游戏保存的数据；删除 App 或清除网站数据也会移除记录。无需申请删除账号，因为本应用没有账号。

4. 支持邮件

如您主动联系 540933120@qq.com，我们会收到发件地址及您主动提供的消息和附件，仅用于回复和解决问题。请勿发送不必要的个人信息。邮件经过您的邮件服务及 QQ 邮箱服务；我们只在解决请求和必要后续期间保留相关支持内容，法律要求保留的情况除外。您可使用同一邮箱申请查阅、更正或删除直接提供的支持信息。

5. 本网站与外部服务

本隐私和支持页面由 GitHub Pages 托管，没有分析脚本、广告、第三方字体或追踪 Cookie。访问页面会与 GitHub 建立连接，GitHub 可能处理 IP 地址及服务器日志，用于服务和安全；这与离线游戏数据分开，详情见 GitHub 隐私声明。打开支持网页或邮件需要网络，网站不能读取游戏本地进度。

6. 儿童与政策更新

游戏不会主动向儿童索取或收集个人信息。儿童如需联系支持，建议由监护人协助，避免提供儿童身份信息。若产品的数据处理方式发生变化，我们会更新本政策和日期。

7. 联系

English

No personal data collected in the game

Pocket Xiangqi is developed by Peng Lin. No account is required. The game has no advertising, analytics, tracking SDKs, in-app purchases, chat or leaderboards. We do not receive gameplay records, learning progress or device identifiers and do not track you across apps.

Local storage and deletion

Games, undo history, difficulty, language, sound and animation preferences, and lesson/puzzle progress are stored on your device to restore play. The iOS app bundles all resources and works offline. The web version can cache resources for offline play. Data is not uploaded to us. Any operating-system-managed backup is governed by your device settings. Erase progress in Settings, delete the app, or clear website data to remove saved records. No account deletion is needed because there are no accounts.

Permissions

The game does not request camera, microphone, location, contacts or photo access. Sounds are synthesized and played locally; no audio is recorded.

Support messages

If you email 540933120@qq.com, we receive your sender address and the content and attachments you choose to provide. We use them only to handle your request and necessary follow-up. Please avoid unnecessary personal information. Your email provider and QQ Mail process the message under their own policies. We retain support content only as needed to resolve requests and necessary follow-up, except where law requires retention. Contact the same address to request access, correction or deletion of information you sent directly.

This website

GitHub Pages hosts these support and privacy pages. We add no analytics, ads, external fonts or tracking cookies. GitHub may process IP addresses and server logs to operate and secure its service; see the GitHub Privacy Statement. This is separate from offline game data. The website cannot read your game progress. Opening websites or email requires connectivity.

Children and updates

We do not solicit personal data from children. A guardian should assist children who need support and avoid sending identifying information. We will update this policy and its date if data practices change. Developer and privacy contact: Peng Lin, 540933120@qq.com.
